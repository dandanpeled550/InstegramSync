# Task boards

Owned by `tech-lead`. One file per milestone (`M0.md`, `M1.md`, …). Each task uses the brief template
from [docs/AGENTS_PLAN.md §7.2](../AGENTS_PLAN.md) and is checked off only when its PR is merged into `dev`.

Status markers: `[ ]` todo · `[~]` in progress (PR link) · `[x]` merged · `[!]` blocked (reason).

Human steps are marked **HUMAN** — agents never do them.
